# Kadosh Finanzas — descargas

Instaladores de la aplicación de escritorio de **Kadosh Finanzas**: el sistema completo en tu
computador, con tus datos en tu equipo. Aquí sólo están las versiones publicadas (en
[Releases](../../releases)); el código no está en este repositorio.

## Descargar la última versión

| Sistema | Enlace directo |
|---|---|
| Windows 10 y 11 (64 bits) | [KadoshFinanzas-win-x64.exe](../../releases/latest/download/KadoshFinanzas-win-x64.exe) |
| Mac con Apple Silicon (M1, M2, M3, M4…) | [KadoshFinanzas-mac-arm64.dmg](../../releases/latest/download/KadoshFinanzas-mac-arm64.dmg) |
| Mac con procesador Intel | [KadoshFinanzas-mac-x64.dmg](../../releases/latest/download/KadoshFinanzas-mac-x64.dmg) |
| Linux (AppImage, casi cualquier distribución) | [KadoshFinanzas-linux-x64.AppImage](../../releases/latest/download/KadoshFinanzas-linux-x64.AppImage) |
| Debian, Ubuntu, Linux Mint (.deb) | [KadoshFinanzas-linux-x64.deb](../../releases/latest/download/KadoshFinanzas-linux-x64.deb) |

Estos enlaces siempre llevan a la versión más reciente.

## La primera vez

Los instaladores todavía no están firmados:

- **Windows**: si aparece «Windows protegió su PC», pulsa **Más información** → **Ejecutar de todas formas**.
- **macOS**: clic derecho sobre la aplicación → **Abrir** (o `xattr -dr com.apple.quarantine "/Applications/Kadosh Finanzas.app"`).
- **Linux**: `chmod +x KadoshFinanzas-linux-x64.AppImage` y ábrela; el .deb se instala con `sudo apt install ./KadoshFinanzas-linux-x64.deb`.

La aplicación avisa sola cuando hay una versión nueva. Al actualizar, tus datos no se tocan.
